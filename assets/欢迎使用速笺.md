# 欢迎使用速笺

速笺（SuJot）是一册**自己托管**的 Markdown 笔记：正文就是磁盘上的 `.md` 文件，
没有数据库、没有外部服务，数据只在你自己那台服务器上。

## 先走一遍基本动作

1. 左边「文件」栏挑一篇打开；`Ctrl + N` 新建
2. 正文栏左上角切换 **编辑 / 分栏 / 预览** —— 分栏时源码与预览滚动锁定
3. 停笔 2.5 秒自动保存；`Ctrl + S` 立刻存
4. 右侧「大纲」把标题聚成目录，滚到哪亮到哪，点一下就到那一段

## 附带的几篇样板

- 功能演示 —— 这一版编辑器支持什么，一篇看完
- 快捷键 —— 全部键位
- 数学与代码 —— 公式和代码块长什么样

> 样板笔记是速笺自带的，看完随手删掉，不影响使用。
