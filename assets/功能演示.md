## 引用与代码

> 引用块会缩进并加一条竖线。
> 第二行仍在引用里。

```python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

print([fib(i) for i in range(10)])
```
