# 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl + K` | 搜索全部笔记（↑↓ 挑选，回车翻开） |
| `Ctrl + S` | 即刻存盘 |
| `Ctrl + ⇧ + S` | 导出本篇为 Markdown 文件 |
| `Ctrl + N` | 新铺一篇 |
| `Ctrl + D` | 收藏 / 取消收藏当前这篇 |
| `?` | 唤出快捷键面板 |
| `Tab` | 编辑器里插入缩进 |
| `Esc` | 关掉当前浮层 |
| 粘贴图片 | 截图 `Ctrl + V` 直接贴进正文，自动上传 |

## 鼠标与手势

- **点标题**：大纲里轻点一下，正文跳到那一段
- **拖分界**：文件栏 / 正文栏 / 大纲栏之间的竖线都能拖；双击复位
- **右键**：文件树上可新建、重命名、删除、导出
- **左上角 logo**：任何时候回到欢迎界面
