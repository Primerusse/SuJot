# 部署到服务器（速查）

目标：一台干净的 Linux 服务器 → 打开你的域名就能用。全程约 10 分钟。

## 0. 前提

| 需要 | 说明 |
| --- | --- |
| Linux 服务器 | 1 核 1G 够用（服务常驻内存约 40–60MB） |
| Python 3.8+ | `python3 -V` 看一眼，绝大多数系统自带；没有就 `sudo apt install python3` |
| nginx | `sudo apt install nginx` |
| 一个域名 | A 记录指向服务器 IP |
| sudo 权限 | 装服务、改 nginx 都要 |

## 1. 放代码

```bash
# 方式一：从 GitHub 克隆（推荐，以后好升级）
sudo git clone https://github.com/<你的用户名>/sujot.git /srv/sujian

# 方式二：在本包解压出来的目录里执行（把当前目录内容传上去）
sudo mkdir -p /srv/sujian && sudo cp -a . /srv/sujian/
```

## 2. 一条命令装成服务

```bash
cd /srv/sujian && sudo deploy/install-service.sh
```

它会检查 Python 版本、建好 `/srv/sujian`、写好 `/etc/systemd/system/sujian.service` 并立刻启动，
然后打印 nginx + 证书那几步。

想改端口 / 数据目录 / 服务名：`sudo deploy/install-service.sh --port 8013 --base /srv/sujian --name sujian`

## 3. nginx 反代 + HTTPS

```bash
sudo cp deploy/nginx.conf.example /etc/nginx/sites-available/sujian
sudo sed -i 's/sujot.example.com/你的域名/g' /etc/nginx/sites-available/sujian
sudo ln -sf /etc/nginx/sites-available/sujian /etc/nginx/sites-enabled/sujian
sudo nginx -t && sudo systemctl reload nginx

sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名
```

防火墙 / 云安全组放行 **80 和 443**；**不要**放行 8013（后端只给本机 nginx 用）。

## 3.5 想改参数

端口、上传上限、历史保留份数这些都在项目根的 **`_config.json`** 里，改完 `sudo systemctl restart sujian` 生效。
systemd 的 `Environment=` 和环境变量优先级更高，会盖过它。

## 4. 首次登录

打开 `https://你的域名`，用初始账号 **`admin` / `admin`** 登录，页面会立刻要求改用户名和密码，
改完才能真正开始写（没改完之前，保存、新建、删除等写接口一律拒绝）。

## 5. 备份 / 升级

```bash
# 备份（数据全在 /srv/sujian 一个目录里）
sudo tar czf /root/sujot-$(date +%F).tar.gz -C /srv sujian

# 升级
cd /srv/sujian && sudo git pull && sudo systemctl restart sujian
```

## 卡住了？

| 现象 | 处理 |
| --- | --- |
| 打开 404 / 白屏 | 确认 `static/` 和 `server.py` 在一起 |
| 登录后又被弹回登录页 | 没走 HTTPS。登录 Cookie 带 `Secure`，纯 HTTP 下浏览器不保存 |
| 字体 / 公式 404 | `static/vendor/` 没传全，用 `deploy/deploy-to-server.sh` |
| 服务起不来，日志说切工作目录失败 | 代码或数据目录在 `/tmp` 下而开了 `PrivateTmp`，改用 `/srv` |
| 粘贴大图报 413 | nginx 里 `client_max_body_size` 调大（示例给了 16m） |

更细的说明见仓库根目录的 `README.md`「部署到服务器」一节。
